# mikuflick02_soundpack
soundpack for mikuflick/02

installation guide:

1.Connect your jailbroken device to Mac or PC
2.Open the destination folder .../MikuFlick02/Documents
3.Pull the MikuFlick02.dat to .../MikuFlick02/Documents
4.Back to .../MikuFlick02/Library and make a folder named "InstallData"
5.Go to .../MikuFlick02/Documents/InstallData and pull all unzipped folders to it.
